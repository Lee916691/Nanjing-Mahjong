# 牌桌视觉与交互设计

2026-09-24更新。参考[雀魂公开对局画面](https://www.4gamer.net/games/517/G051738/SS/005.jpg)的四向桌面组织：中央局况、环绕式牌河、边缘手牌和座位方向。新版本见refined-table-and-scoring.md。麻将图案使用SVG重绘，中文字形使用OFL授权的Noto Serif SC轮廓。

## 牌面与信息

- 万子使用汉字数字和红色萬字；筒子使用环状圆点；条子使用竹节，一条为鸟形。
- 风牌、三元牌、植物花与季节花分别绘制，保留每张牌的可访问名称。
- 南京玩法中中、发、白仍为花牌；界面不引入日麻的吃牌或立直规则。
- 玩家卡显示姓名、座位、庄家、连接、手牌张数与累计分。
- 中央显示圈次、庄次、手数和余牌，行动位浅色高亮。

## 位置与操作

- 自己位于下方；下家、对家、上家按-90°、180°、90°显示牌。
- 牌河每行六张，最新弃牌使用金色描边；超过可视高度时可滚动查看，不截断数据。
- 花牌和副露分区；被碰杠的公开牌横置，补杠第四张叠放。
- 新摸入的自有牌放在手牌右端，与原手牌留间隔。
- 单击选牌、按钮确认；悬停或选中时仅高亮已公开区域的同牌。
- 单局结算显示四人分数变化和付款明细，可以临时收起查看牌桌。
- 提供牌面说明、全屏开关和减少动画偏好的支持。

## 实现边界

1280×760的桌面坐标通过ResizeObserver整体适配可用空间，牌面为可缩放矢量。桌面目标分辨率为1366×768及1920×1080。

PlayerGameView新增私有drawnTileId，仅向牌的所有者返回；副露新增公开claimedTileId/fromSeat用于朝向展示。客户端不推断隐藏牌或推进规则。

## 验证

四人真实Socket.IO交互回归通过。新增中后盘浏览器场景含64张弃牌、碰/暗杠/补杠、花牌和新摸牌，验证牌河互不重叠、副露不遮挡玩家卡、同牌高亮、选牌确认、全屏及结算展示。两个目标分辨率的截图均已检查。
