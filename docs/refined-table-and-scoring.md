# 精制牌面、玩家牌区与结算说明

更新：2026-09-24。本轮以高品质实体麻将的象牙白树脂、嵌色字样及克制的桌游界面为方向。

## 牌面

- 全套重绘：万子、筒子、条子、风牌、三元牌与八种花牌。
- 中文字样使用Noto Serif SC 750字重的矢量轮廓，统一字形和光学居中，不依赖玩家电脑的字体回退。字形源于Google Fonts，授权见assets/OFL-NotoSerifSC.txt。
- 筒子统一环径和间距；条子改为带节点的竹节；一条为双色鸟形。花牌各自绘制植物或季节图案。
- 使用墨蓝、松绿、朱红三种主体色，保留传统识别方式；牌体为象牙白、窄倒角和轻阴影。
- 牌面说明内可查看完整牌面图鉴。

## 归属与摆放

- 每位玩家的暗手、花牌和碰杠牌组成同一块牌区，随座次一起旋转。
- 本人的花牌与碰杠位于手牌正上方，明确标注“我的 · 花牌”和“我的 · 碰 / 杠”。
- 公开区只使用服务端已有的公开数据；新摸牌信息仍仅发送给本人。
- 超多花牌可横向滚动查看，副露保留来源横置与补杠叠放。

## 结算

- 自动开始下一手前的停留时间由10秒改为45秒，断线仍冻结倒计时。
- 展示底分、每个牌型、硬花与各类软花的得分项，以及比下胡、抢补杠等倍率。
- 例如“门清、硬花3个、缺一1花”显示：`(10+10+6+2)×2=56`。
- 单笔金额、付款笔数、本项总额及每笔付款人分别列出，避免自摸或承包重复乘三。
- 天胡按每家1000定额展示，不套用普通倍率。
- 计算说明由核心规则和服务端保存为快照；浏览器仅展示，不计算权威分数。
- 旧记录缺少计算快照时保留付款金额，不反推具体牌型或软花来源。
- 收起结算后，可从结算明细回看；整将结束页保留最后一手的完整明细。

## 验证范围

四人联机回归；本人有两组碰牌的归属与间距；1366×768和1920×1080布局；全牌面图鉴；真实规则生成的56分示例；结算倒计时、收起和回看。既有计分规则不变。

## 条子图案修订

条子改用Noto Sans Symbols 2中OFL授权的传统麻将轮廓，去除Unicode外框，重新设定占幅、居中与红绿分色。竹索笔画加粗，六条采用三列两排，八条采用上下折索，一条采用栖鸟纹样。授权随assets/OFL-NotoSansSymbols2.txt保存。放大预览与实际牌桌截图已检查；本次为图案展示修改。

## 全套牌面统一

万子、筒子、东南西北、中发白及八种花牌已改用与新版条子同系列的Noto Sans Symbols 2传统麻将轮廓，并统一去框、居中、缩放及分色。万子上部墨蓝、下部红萬；筒子以较粗圆环和传统排列呈现；风牌墨蓝、中红、发绿、白板墨蓝；植物和季节花牌保留各自纹样。素材使用SIL OFL 1.1授权，详见assets/OFL-NotoSansSymbols2.txt。新版条子沿用已认可的图案。
