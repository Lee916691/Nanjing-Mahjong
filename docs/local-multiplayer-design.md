# 本地好友联机约定

使用现有 V1.0.8 麻将规则。技术性的掉线、会话和房间策略如下，不增加自动托管玩法：

- 同源匿名 HttpOnly 会话，固定四座；准备完成后房主开始。
- 掉线保留座位并暂停；四人在线后恢复。同一身份新连接接管旧连接。
- 客户端只提交服务端发出的动作令牌，内部动作不进入网络协议。
- SQLite 事务保存状态、命令回执和结算；先提交再广播。
- 每位玩家单独收到白名单视图，响应选择只回发本人。
- 结算停留45秒，断线冻结；有效庄次由规则引擎决定。
- 匿名会话不支持清除 Cookie 或跨设备后的恢复。
- 服务监听地址与端口可配置，网页/API/Socket.IO 同源。
