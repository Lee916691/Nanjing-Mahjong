## 1. V1 实现范围

### 1.1 本版本包含

- 四人游戏；
- 南京麻将“敞开头”规则；
- 144张牌；
- 不允许吃，允许碰、明杠、暗杠、补杠；
- 点炮、自摸、一炮多响；
- 抢补杠；
- 普通胡、门清、对对胡、全球独钓、混一色、清一色、七对、龙七对、无花果、压绝、天胡、地胡、花开、杠开；

- 比下胡；
- 庄家、连庄、不过庄和流局；
- 每人初始1000分，允许负分；
- 记录累计分数；
- 系统自动记录并推进完整一将牌；
- 一将牌按16个有效庄次及第16局特殊续庄规则结束；

- 345、花一规则；
- 二人或三人游戏；
- AI玩家；
- 排位、匹配、金币或现金系统。

## 2. 基本术语

### 2.1 玩家与座次

固定四名玩家，座次为：

- 东
- 南
- 西
- 北

出牌、摸牌和庄家轮换使用唯一行动顺序：

```text
东 → 南 → 西 → 北 → 东
```

“下家”指上述顺序中的下一位玩家。

桌面坐标仅用于UI显示，不参与任何逻辑计算：

```text
        北
东            西
        南
```

### 2.2 牌墙头部和尾部

- 正常摸牌：从牌墙头部摸；
- 补花、明杠、暗杠、补杠后的补牌：从牌墙尾部摸；
- 不设置死墙、王牌区或保留牌；
- 所有牌均可被摸取；
- 牌墙无法继续提供合法摸牌或补牌时，按流局处理。

### 2.3 手牌、副露与花牌区

- 手牌：当前参与胡牌结构判断的未公开牌；
- 副露：碰、明杠、补杠、暗杠形成的公开或记录牌组；
- 花牌区：玩家已经亮出的20类花牌实体；
- 花牌不进入手牌，不参与顺子、刻子、对子、杠或胡牌结构。

## 3. 牌的组成

共144张。

### 3.1 普通牌：124张

#### 数字牌：108张

- 万子：一万至九万，每种4张，共36张；
- 条子：一条至九条，每种4张，共36张；
- 筒子：一筒至九筒，每种4张，共36张。

#### 风牌：16张

- 东、南、西、北，每种4张。

### 3.2 花牌：20张

以下牌全部视为花牌：

- 红中4张；
- 发财4张；
- 白板4张；
- 梅、兰、竹、菊各1张；
- 春、夏、秋、冬各1张。

花牌规则：

1. 不参与手牌；
2. 不参与胡牌结构；
3. 不可碰、杠或组成对子、刻子；
4. 摸到后立即亮出；
5. 从牌墙尾部补牌；
6. 每张花牌计1个硬花；
7. 补到的仍是花牌时，继续亮出并补牌。

## 4. 开局、发牌与初始补花

### 4.1 开局庄家

第一局随机确定一名庄家。

### 4.2 发牌数量

- 庄家初始获得14张牌；
- 其余三家各获得13张牌。

花牌不保留在手牌中，发牌结束后进入初始补花阶段。

### 4.3 初始补花顺序

按以下顺序进行：

```text
庄家 → 庄家下家 → 对家 → 上家
```

每名玩家轮到补花时：

1. 将自己所有花牌全部亮出；
2. 从牌尾补牌；
3. 补到花牌则继续补；
4. 直到手中恢复为全部普通牌；
5. 该玩家补完后，再轮到下一名玩家。

### 4.4 初始花杠结算

玩家在发牌和初始补花过程中凑成花杠时，立即结算花杠分。

### 4.5 地胡报听时点

所有玩家完成初始补花后、庄家第一次出牌前，闲家可以选择报地胡听牌。

### 4.6 开局行动

初始补花和地胡报听结束后，由庄家开始第一次出牌。

## 5. 回合流程

### 5.1 正常回合

通常流程为：

```text
当前玩家摸牌
→ 处理花牌或可选杠
→ 当前玩家出牌
→ 其他玩家判断胡、碰或明杠
→ 若无人操作，由下一位玩家摸牌
```

庄家开局已经有14张普通牌，因此第一回合直接出牌，不再正常摸牌。

### 5.2 碰牌后限制

玩家碰牌后：

1. 必须先打出一张牌；
2. 在打出该牌之前，不得暗杠；
3. 在打出该牌之前，不得补杠。

### 5.3 操作优先级

对同一张弃牌：

```text
胡 > 碰 / 明杠
```

由于每种普通牌只有4张，同一张弃牌不会同时出现两家都能碰或明杠的情况，因此不设置碰与杠之间的额外优先级。

### 5.4 一家或多家胡牌

- 任意玩家胡牌后，本局立即结束；
- 支持一炮多响；
- 一炮多响时，所有满足条件并选择胡牌的玩家同时结算；
- 本局结束后不再处理碰或杠。

## 6. 杠规则

### 6.1 明杠

其他玩家打出一张牌时，某玩家手中已有三张相同牌，可以选择明杠。

- 明杠形成一组面子；
- 明杠者从牌尾补一张牌；
- 点杠者向明杠者支付10分；
- 明杠不破坏门清；
- 同一次明杠计一嘴。

### 6.2 暗杠

玩家在自己的出牌阶段，手中有四张相同牌时，可以选择暗杠。

- 暗杠形成一组面子；
- 从牌尾补一张牌；
- 其他三家各向暗杠者支付5分；
- 暗杠不破坏门清；
- 暗杠软花+2；
- 若为风牌暗杠，同时计算风向刻软花+1；
- 暗杠会参与三嘴锁嘴计算；
- 玩家可以选择不暗杠。

### 6.3 补杠

玩家此前碰过一组牌，之后自己摸到第四张相同牌时，可以选择补杠。

- 补杠成功后，从牌尾补一张牌；
- 原先点碰者向补杠者支付10分；
- 补杠不新增一嘴；
- 补杠软花+1；
- 若为风牌补杠，同时计算风向刻软花+1；
- 玩家可以选择不补杠；
- 补杠声明后，其他玩家先获得抢杠胡机会；
- 无人抢杠后，补杠才正式成立并结算。

### 6.4 杠后连续处理

每次杠后从牌尾补一张牌：

- 补到花牌：亮花并继续从牌尾补；
- 补到可暗杠或补杠的牌：在满足操作限制时可继续杠；
- 最终获得普通牌后，可以胡、继续杠或出牌。

### 6.5 无牌可补

- 牌尾没有牌时，不允许开杠；
- 最后一张牌若摸到花牌，玩家无需出牌，立即流局；
- 最后一张牌即使使玩家凑成花杠，也不结算该花杠。

## 7. 门清

### 7.1 门清定义

玩家没有保留任何“碰牌副露”时，视为门清。

以下操作不破坏门清：

- 暗杠；
- 直接明杠；
- 补杠成功后的杠组。

### 7.2 碰后恢复门清

- 玩家碰牌后暂时不门清；
- 如果该碰牌后来成功补杠，则该组不再视为碰牌；
- 若玩家所有碰牌组最终都成功补杠，则恢复门清；
- 如果仍有至少一组未补杠的碰牌，则不门清。

补杠被抢杠时本局立即结束，不需要继续判断之后是否恢复门清。

---

## 8. 基础胡牌结构

### 8.1 普通结构

除七对、龙七对外，胡牌必须满足：

```text
4组面子 + 1对将牌
```

面子包括：

- 数字牌顺子；
- 刻子；
- 碰；
- 明杠；
- 暗杠；
- 补杠。

杠虽然包含4张相同牌，但在胡牌结构中只算1组面子。

### 8.2 顺子限制

- 顺子只能由万、条、筒组成；
- 风牌不能组成顺子；
- 花牌不参与胡牌结构。

### 8.3 七对结构

七对由7个对子组成。

同一种牌的4张可视为两个对子，但：

- 不算暗杠；
- 不计算暗杠软花。

## 9. 胡牌资格

### 9.1 点炮与自摸

- 允许点炮；
- 允许自摸；
- 点炮由点炮者支付；
- 自摸由其他三家分别支付。

### 9.2 小胡硬花限制

普通小胡必须至少有4个硬花才能胡。

### 9.3 不受硬花限制的牌型

最终牌型满足以下任意一种时，即使硬花少于4个，也可以胡：

- 门清；
- 七对；
- 龙七对；
- 混一色；
- 清一色；
- 对对胡；
- 全球独钓。

例如：

- 门清平胡、0硬花，可以胡；
- 不门清对对胡、0硬花，可以胡；
- 不门清混一色、0硬花，可以胡。

### 9.4 一炮多响

- 同一张弃牌可以被多名玩家同时胡；
- 每名胡牌者独立计算自己的牌型、花数和得分；
- 点炮者分别向每位胡牌者付款；
- 发生一炮多响时，本局立即结束；
- 一炮多响属于不过庄情况。

## 10. 牌型定义

### 10.1 平胡

最普通的胡牌方式，且不属于门清。

456规则牌型加分：0。

### 10.2 门清

符合第7章门清定义的胡牌。

456规则牌型加分：+10。

### 10.3 对对胡

除将牌外，四组面子全部为刻子、碰或杠，不含顺子。

456规则牌型加分：+30。

### 10.4 全球独钓

玩家已经碰或杠出四组牌，手中只剩最后一张单牌等待配对成将。

456规则牌型加分：+80。

计分规则：

- 全球独钓只计算全球独钓分；
- 不再叠加对对胡分。

### 10.5 混一色

最终胡牌结构只包含：

- 万、条、筒中的一种数字花色；
- 以及东、南、西、北风牌。

中、发、白是花牌，不参与手牌，因此不存在是否计入混一色的问题。

456规则牌型加分：+30。

### 10.6 清一色

最终胡牌结构只包含万、条、筒中的一种数字花色，不包含其他数字花色和风牌。

456规则牌型加分：+40。

### 10.7 七对

由7个对子组成。

七对天然门清，可以与以下牌型叠加：

- 门清；
- 清一色；
- 混一色；
- 无花果；
- 其他实际满足且未被明确排除的项目。

456规则牌型加分：+50。

### 10.8 龙七对

龙七对是特殊七对。

判定条件：

1. 最终牌型为七对；
2. 其中存在一组4张相同牌；
3. 胡牌前该牌已有3张；
4. 最终胡到第4张相同牌，形成“龙头”。

规则：

- 自摸第4张和点炮第4张都算龙七对；
- 如果手中已有4张相同牌，而最后胡的是其他牌，只算普通七对；
- 如果手中存在两个四张组，只要最终胡到的是其中一个四张组的第4张，仍算龙七对；
- 多个四张组不产生额外龙七加分；
- 龙七对只加龙七对分，不再加普通七对分；
- 四张相同牌不算暗杠，不计算暗杠软花。

456规则牌型加分：+100。

### 10.9 无花果

玩家胡牌时硬花数为0。

456规则牌型加分：+30。

无花果不单独放宽胡牌资格。通常需要同时满足门清或其他不受4硬花限制的牌型才能合法胡牌。

### 10.10 压绝

条件：

1. 玩家只听一个牌种；
2. 该牌种此前已经被任意玩家碰过；
3. 自己碰过也算；
4. 抢补杠时，若被抢的牌正是该压绝牌，可以形成“抢杠压绝”。

456规则牌型加分：+30。

压绝可以与门清、混一色、无花果等其他牌型叠加，但不再计算压当、边张、独占的单听软花。

### 10.11 天胡

庄家在第一次出牌前胡牌，算天胡。

包括：

- 庄家初始普通牌已经胡；
- 庄家在初始补花后补到胡牌。

天胡结算：

- 其他三家各支付庄家1000分；
- 不计算其他牌型；
- 不计算硬花、软花；
- 不受比下胡影响；
- 比下胡时仍为每家1000分；
- 此前已触发的花杠等实时得分正常保留；
- 天胡后庄家连庄。

### 10.12 地胡

闲家在所有玩家初始补花完成后、庄家第一次出牌前，处于听牌状态时，可以选择报地胡。

规则：

- 庄家不能报地胡；
- 必须主动报听；
- 可以选择不报，不报则之后胡牌不算地胡；
- 报听后不能碰；
- 可以点炮胡，也可以自摸；
- 地胡状态持续到胡牌或流局；
- 可以放弃一次点炮，仍保持地胡状态；
- 可以明杠或暗杠，但杠前后听牌集合必须完全不变；
- 若杠会改变听牌集合，则禁止开杠；
- 地胡可以与门清、清一色、七对、花开、杠开等项目叠加。

456规则牌型加分：+30。

### 10.13 花开

玩家摸到花牌，从牌尾补花后，因该补花牌自摸胡牌，算花开。

456规则牌型加分：+10。

### 10.14 杠开

玩家明杠、暗杠、补杠或形成花杠后，从牌尾补牌并自摸胡牌，算杠开。

456规则牌型加分：+20。

### 10.15 花开与杠开互斥

只看最终产生自摸牌的直接补牌原因：

- 杠后补到花，再补花后自摸：算花开；
- 花后补到可杠牌，开杠后补牌自摸：算杠开；
- 同一次胡牌不同时计算花开和杠开。

## 11. 硬花与软花

### 11.1 花数公式

```text
花数 = 硬花数 + 软花数
```

456花二规则中：

```text
花分 = 花数 × 2
```

### 11.2 硬花

每亮出一张花牌，硬花+1。

包括：

- 红中；
- 发财；
- 白板；
- 梅兰竹菊；
- 春夏秋冬。

### 11.3 缺一

最终胡牌结构中，完全不包含万、条、筒中的某一门，软花+1。

判断范围包括：

- 手牌；
- 碰牌副露；
- 所有杠牌副露。

规则：

- 只缺一门时加1；
- 同时缺两门时，实际已经构成混一色或清一色，不再计算缺一；
- 混一色、清一色不计算缺一；
- 七对、龙七、对对胡、全球独钓若并非混一色或清一色，仍可计算缺一。

### 11.4 压当、边张、独占

只听一个牌种，并符合以下结构之一时，软花+1：

- 压当：中间张等待，例如二万、四万听三万；
- 边张：一二听三，或八九听七；
- 独占：单钓将牌。

以下牌型不计算该软花：

- 对对胡；
- 全球独钓；
- 龙七对；
- 七对；
- 压绝。

三种情况互斥，同一次胡牌最多加1软花。

仅仅“候选听牌很多但桌面只剩一种”不算。必须从牌型结构上只听一个牌种。

### 11.5 明杠和补杠

每组明杠或补杠，软花+1。

### 11.6 暗杠

每组暗杠，软花+2。

### 11.7 风向刻

每组东、南、西、北的刻子或杠，软花+1。

包括：

- 手牌暗刻；
- 碰；
- 明杠；
- 补杠；
- 暗杠。

风向刻可以与杠软花叠加。例如东风暗杠：

```text
暗杠 +2
风向刻 +1
合计 +3软花
```

## 12. 胡牌计分

### 12.1 基本公式

除天胡和特殊强制结算外：

```text
单份胡牌分
= 底分10
+ 所有可叠加牌型加分
+ 花数 × 2
```

### 12.2 456牌型加分表

| 项目     | 加分 |
| -------- | ---: |
| 平胡     |    0 |
| 门清     |   10 |
| 对对胡   |   30 |
| 混一色   |   30 |
| 无花果   |   30 |
| 清一色   |   40 |
| 七对     |   50 |
| 全球独钓 |   80 |
| 龙七对   |  100 |
| 压绝     |   30 |
| 花开     |   10 |
| 杠开     |   20 |
| 地胡     |   30 |

天胡不使用此公式，固定每家1000分。

### 12.3 牌型叠加

除以下排除关系外，满足的项目可以叠加：

- 龙七对不叠加普通七对；
- 全球独钓不叠加对对胡；
- 花开与杠开互斥；
- 混一色、清一色不计算缺一；
- 压绝、七对、龙七对、全球独钓、对对胡不计算压当、边张、独占软花。

### 12.4 点炮

- 点炮者向胡牌者支付1份胡牌分；
- 其他玩家不支付；
- 没有庄家加倍。

### 12.5 自摸

- 其他三家分别向胡牌者支付1份胡牌分；
- 胡牌者合计获得3份；
- 没有庄家加倍。

### 12.6 一炮多响

每位胡牌者独立计算：

- 自己的牌型；
- 自己的硬花和软花；
- 自己的单份胡牌分。

点炮者分别向每位胡牌者支付1份。

---

## 13. 抢杠胡

### 13.1 允许范围

只允许抢补杠，不允许抢暗杠或直接明杠。

### 13.2 流程

1. 玩家声明补杠；
2. 其他玩家获得抢杠胡机会；
3. 若有人胡，补杠失败；
4. 原副露仍保持为碰；
5. 不结算补杠10分；
6. 不从牌尾补牌；
7. 补杠声明者视为点炮者；
8. 支持一炮多响；
9. 本局立即结束。

### 13.3 计分

每位抢杠胡玩家：

```text
获得 = 自己的单份胡牌分 × 3
```

由补杠声明者单独支付，其他两家不支付。

若多人同时抢杠胡，补杠者分别向每名胡牌者支付其胡牌分×3。

抢杠属于不过庄情况。

### 13.4 抢杠压绝

若被补杠的牌同时满足压绝条件，抢杠胡可以叠加压绝牌型分。

---

## 14. 过手胡

### 14.1 触发

其他玩家打出一张当前玩家可以胡的牌，当前玩家选择不胡，或响应超时自动过。

### 14.2 限制

从放弃胡牌开始，直到该玩家自己打出一张牌前：

- 不能胡其他玩家点炮；
- 即使之后点炮分数更高也不能胡；
- 不能抢杠胡；
- 可以自摸胡。

### 14.3 解除

以下情况均可解除过手状态：

- 正常摸牌后打出一张牌；
- 碰牌后打出一张牌；
- 杠牌并完成后续操作，最终打出一张牌。

### 14.4 过碰

放弃碰牌不产生过手限制。之后若再次出现可碰情况，仍可碰。

---

## 15. 庄家、连庄与有效局数

### 15.1 普通过庄

如果庄家没有胡牌，且本局不属于特殊不过庄情况，由庄家的下家接庄。

换庄顺序：

```text
东 → 南 → 西 → 北 → 东
```

### 15.2 连庄

庄家胡牌时，庄家继续坐庄。

### 15.3 特殊不过庄

不论胡牌者或付款者是谁，以下情况均不过庄：

- 大杠开花，即杠开；
- 一炮多响；
- 抢杠胡；
- 三嘴包子；
- 三清包子；
- 全球包子；
- 流局。

### 15.4 局数统计

完整一场为16个有效庄次，即四圈。MVP 必须自动记录并推进完整一将牌。

规则：

- 只有发生正常过庄时，有效庄次+1；
- 只要庄家不变，本把不计入16个有效庄次；
- 第16个有效庄次必须一直打到下一次正常过庄，且未触发第16局特殊续庄条件，才算完成；
- 系统必须记录有效过庄次数、圈数、当前庄家、当前是否处于第16局和第16局特殊续庄状态；
- 满足第26章定义的一将牌结束条件后，系统必须自动结束整场游戏；
- 房主可以提前结束或解散房间，但该管理功能不能作为正常完成一将牌的替代方案。

---

## 16. 流局

以下情况流局：

1. 所有可摸牌全部耗尽，仍无人胡牌；
2. 玩家正常摸到最后一张牌，而该牌是花牌，无法继续补花；
3. 其他导致无法继续合法摸牌或补牌的情况。

流局结果：

- 本局无人获得胡牌分；
- 已经实时结算的杠分、花杠、罚分和四风归齐等不撤销；
- 庄家继续坐庄；
- 不增加有效局数。

---

## 17. 实时结算

实时结算在触发时立即修改累计分数，即使之后流局也不撤销。

### 17.1 比下胡

敞开头每把都比下胡。

除天胡外，所有得分和付分翻倍，包括：

- 胡牌；
- 点炮；
- 自摸；
- 抢杠；
- 花杠；
- 明杠；
- 补杠；
- 暗杠；
- 跟打一圈；
- 同牌打四张；
- 四风归齐；
- 承包支付。

天胡固定每家1000，不翻倍。

文档中的基础分值均为未翻倍分。实际结算时统一乘2。

### 17.2 跟打一圈

仅四人游戏启用。

触发条件：

1. A打出某牌；
2. 接下来按正常座次顺序；
3. 其他三名玩家各自下一次弃牌都打出同一牌种；
4. 中间无人因碰或杠改变正常行动座次；
5. 第三家跟出时触发。

结算：

- A向其他三家各付5分；
- 比下胡后实际各付10分。

补充：

- 若碰或杠改变座次，则本次跟打一圈判定取消；
- 若没有改变座次，某玩家碰牌后打出该牌，也可以算跟牌；
- 同一局可多次触发。

### 17.3 同一玩家打出四张相同牌

若同一玩家累计打出同一牌种的4张实体牌，第4张打出时触发。

结算：

- 该玩家向其他三家各付5分；
- 比下胡后实际各付10分；
- 同一牌种最多触发一次；
- 即使先前打出的牌后来被碰走，仍计入“曾经打出”。

### 17.4 四风归齐

追踪同一玩家连续多个出牌回合打出的风牌。

触发条件：

- 该玩家连续打出的牌均为东、南、西、北；
- 中间该玩家没有打出非风牌；
- 连续序列中集齐东南西北四种风牌；
- 不要求固定顺序；
- 不要求从开局开始；
- 可包含重复风牌。

结算：

- 其他三家各向该玩家支付5分；
- 比下胡后实际各付10分。

连续序列规则：

- 玩家打出非风牌时，序列清零；
- 中发白属于花牌，不存在作为弃牌的情况；
- `东南西北东南西北`触发2次；
- `东东南南西西北北`在第一张北打出时触发1次，第二张北不再触发；
- 同一局可在新的连续序列中再次触发。

### 17.5 明杠实时分

点杠者向明杠者支付10分；比下胡后支付20分。

### 17.6 补杠实时分

原点碰者向补杠者支付10分；比下胡后支付20分。

### 17.7 暗杠实时分

其他三家各向暗杠者支付5分；比下胡后各支付10分。

## 18. 花杠

### 18.1 花杠组合

以下每一套独立构成一种花杠：

1. 四张红中；
2. 四张发财；
3. 四张白板；
4. 梅、兰、竹、菊各一张；
5. 春、夏、秋、冬各一张。

### 18.2 花杠性质

- 花杠不是普通杠；
- 不占胡牌结构中的面子；
- 不影响手牌结构；
- 不参与门清判断；
- 不算三嘴中的杠；
- 组成花杠的4张花仍分别计4个硬花；
- 同一玩家可在同一局形成多种花杠；
- 每一种具体花杠对同一玩家一局最多触发一次。

### 18.3 花杠结算

形成一套花杠时：

- 其他三家各向花杠者支付10分；
- 比下胡后实际各支付20分；
- 发牌、初始补花、正常补花过程中均可触发；
- 若摸到整局最后一张牌才形成花杠，因为无法继续补牌，不结算该花杠并立即流局。

### 18.4 花杠后的补牌

形成花杠本身不额外多补一张；花杠由正常摸花和补花流程自然形成。

若形成花杠后，当前补花流程继续并最终自摸，最终胡牌可按杠开计算。

---

## 19. 杠后承包

### 19.1 触发

以下情况触发杠后承包：

- A点给B明杠；
- A此前点给B碰，B之后成功补杠。

A成为本次杠后承包人。

### 19.2 持续时间

从该杠成功开始，持续到B最终打出一张牌为止。

期间可能发生：

- 自摸；
- 花开；
- 再次补杠；
- 暗杠；
- 花杠；
- 四风归齐；
- 其他实时得分。

### 19.3 承包效果

- 只改变付款人；
- 不改变得分项目、分值和牌型；
- 原本应由其他玩家支付给B的分数，全部改由A支付；
- 原本由A自己支付的部分也仍由A支付；
- 最初承包人不会因后续新的杠事件而被替换；
- 始终由最初点杠或原点碰者承包，直到B出牌。

### 19.4 自摸承包

若B在承包持续期间自摸，A支付三家原本应付的全部份额。

### 19.5 链式得分

若B在承包持续期间再次补杠、暗杠、形成花杠或触发其他实时得分，均由A承担原本其他玩家应支付的部分。

## 20. 三嘴包子

### 20.1 嘴的来源

对玩家B：

- 某玩家A点给B一次碰或明杠，B锁A一嘴；
- B暗杠一次，可为尚有资格的目标玩家增加一嘴；
- 补杠不新增一嘴；
- 花杠不算嘴；
- 一次明杠只算一嘴。

### 20.2 锁定规则

三嘴必须从第一嘴到第三嘴始终锁定同一个唯一玩家。

规则：

1. 若第一嘴由A点碰或点杠产生，B只可能继续锁A；
2. 之后B每次暗杠，可继续给A增加一嘴；
3. 若中途C或D再点给B碰或杠，三嘴包子立即永久失效；
4. 失效后，即使之后A累计再次达到三嘴，也不能恢复；
5. 连续暗杠三次，不形成三嘴包子；
6. 暗杠两次后，A再点B一次碰或明杠，可以形成B锁A三嘴；
7. A点B一次后，B再暗杠两次，也可以形成B锁A三嘴；
8. 达到三嘴时只进入“三嘴包子状态”，不会立即结束牌局；
9. 三嘴状态整局有效，流局或本局结束后清零。

### 20.3 三嘴后的触发情况

B锁A三嘴后：

#### 情况1

C或D再给B点一个碰或明杠：

- 立即结束本局；
- 强制按B“对对胡自摸”结算；
- A承包三家份额。

#### 情况2

C或D点炮B的对对胡：

- 按B“对对胡自摸”结算；
- A承包三家份额。

#### 情况3

A自己再给B点一个碰、明杠，或点炮B的对对胡：

- 立即结束本局；
- 强制按B“全球独钓自摸”结算；
- A承包三家份额。

#### 情况4

B自己摸到暗杠，或B对对胡自摸：

- 立即结束本局；
- 强制按B“全球独钓自摸”结算；
- A承包三家份额。

### 20.4 强制牌型计算

三嘴触发时：

- 不要求B当时实际满足完整普通胡牌结构；
- 强制赋予对对胡或全球独钓；
- 全球独钓不叠加对对胡；
- 可以叠加实际满足的清一色、混一色、无花果、门清、花开、杠开、花数等；
- 门清、无花果、花开、杠开必须实际满足，不能因强制牌型自动获得；
- 由A支付三份自摸分；
- 其他玩家不支付。

三嘴包子属于不过庄情况。

---

## 21. 三清包子

### 21.1 三清形成

玩家A已经副露三组同一类别的碰或杠时，进入三清状态。

可计入的副露：

- 碰；
- 明杠；
- 补杠；
- 已声明的暗杠。

手中未公开的暗刻不算。

### 21.2 数字花色三清

三组均属于同一种数字花色，例如：

- 一万碰；
- 二万碰；
- 三万暗杠。

### 21.3 风牌三清

东、南、西、北被视为一种特殊类别。

例如A已副露：

- 东风；
- 南风；
- 西风；

则进入风牌三清状态。

风牌三清中的“清一色”只在三清承包强制结算时使用；普通自然胡出的全风牌不因此自动算清一色。

### 21.4 三清失效

形成三清后，若发生以下任一情况，三清立即永久失效：

- 其他玩家点给A一个不同数字花色的碰或明杠；
- A暗杠一个不同数字花色；
- A将一个不同数字花色的碰牌补杠。

对于风牌三清，任何万、条、筒副露都会使其失效。

仅仅摸到、持有或打出其他花色，不会使三清失效。

### 21.5 三清触发情况

#### 情况1：点炮清一色

B点炮A实际完成的清一色：

- 按A清一色自摸结算；
- B承包三家份额。

#### 情况2：点出第四组同类碰或杠

B点给A一个与三清同类别的碰或明杠：

- 该操作立即触发本局结束；
- A不需要碰后再打牌；
- 强制按A“清一色全球独钓自摸”结算；
- B承包三家份额。

#### 情况3：点炮清一色对对胡

B点炮A实际完成的清一色对对胡：

- 强制按A“清一色全球独钓自摸”结算；
- B承包三家份额。

#### 情况4：A自摸

A自摸清一色或对对胡：

- 不存在三清承包；
- 按普通自摸由其他三家分别支付。

#### 情况5：A继续同类暗杠

A再暗杠一组同类别牌：

- 无人承包；
- 游戏继续。

#### 情况6：点炮非清一色

B点炮A的非清一色牌型：

- 不触发三清承包；
- B只支付普通点炮的一份；
- 即使牌型是混一色，也只按普通混一色点炮结算。

### 21.6 风牌三清示例

A已副露东、南、西三组，手中还有一对或三张北风。

其他玩家打出北风：

- 若形成点炮或第四组碰/杠触发；
- 按“清一色全球独钓自摸”强制结算；
- 点牌者承包三份。

三清包子属于不过庄情况。

## 22. 全球包子

### 22.1 上全球

玩家完成第四组碰或杠后，只剩一张手牌单钓，称为“上全球”。

### 22.2 通过杠上全球

如果第四组通过以下方式形成：

- 明杠；
- 暗杠；
- 补杠；

则不存在架牌包子。

玩家仍可正常胡全球独钓。

### 22.3 通过碰上全球

如果第四组通过碰形成：

1. 玩家碰后必须打出一张牌；
2. 该牌称为“架牌”；
3. 架牌放在牌桌上作为特殊标记；
4. 架牌对应一个承包范围。

### 22.4 架牌范围

#### 数字牌

与架牌同花色，点数相差不超过2，超出1至9的部分截断。

例如：

- 五万：三、四、五、六、七万；
- 二万：一、二、三、四万；
- 九条：七、八、九条。

#### 风牌

若架牌为东、南、西、北中的任意一种，范围为全部四种风牌。

花牌不能成为架牌。

### 22.5 架牌生效条件

- 玩家上全球后只能单钓一个牌种；
- 如果之后听牌牌种发生变化，架牌永久失效；
- 即使之后听牌再改回原牌种，也不恢复；
- 没有换听时，架牌持续有效。

### 22.6 承包触发

如果另一玩家打出的点炮牌：

- 属于架牌范围；
- 且确实使该全球玩家胡牌；

则：

- 点炮者承包三份全球独钓自摸分；
- 其他玩家不支付。

自摸全球不触发架牌承包，按普通自摸结算。

全球独钓只计算全球分，不叠加对对胡。

全球包子属于不过庄情况。

---

## 23. 承包优先级

同一次结算同时满足多种承包规则时，只采用优先级最高的一种：

```text
三嘴包子
> 三清包子
> 全球包子
> 杠后承包
> 普通点炮 / 自摸
```

规则：

- 不重复支付；
- 不允许多个玩家同时承包同一次得分；
- 即使多条规则指向同一承包者，也只按最高优先级结算一次；
- 低优先级规则被覆盖后，不再额外产生付款。

## 24. 分数与整场游戏

### 24.1 初始分数

四名玩家开局均为1000分。

### 24.2 负分

允许玩家累计分数低于0。

### 24.3 累计结算

- 所有胡牌分、杠分、花杠、罚分和承包均实时计入累计分；
- 本局结束后保留；
- 流局不撤销本局已发生的实时得分。

### 24.4 MVP 结束方式

- 系统必须按16个有效庄次及第16局特殊续庄规则自动结束一将牌；
- 房主可以提前结束或解散房间；
- 房主提前结束或解散房间属于附加管理功能，不能替代自动完成一将牌；
- 结束时显示四名玩家最终累计分和排名。

## 25. 杠开包子

### 25.1 适用场景

A已经锁定B三嘴，B是A的三嘴承包人。A当前处于对对胡听牌状态。

随后发生：

```text
A摸牌
→ A补杠
→ B向A支付补杠分
→ A从牌尾补牌
→ A自摸对对胡
```

由于A已经锁定B三嘴，中途不可能存在其他玩家成为该补杠牌组的原点碰者；若其他玩家曾点给A碰或杠，三嘴状态早已失效。

### 25.2 结算方式

该胡牌强制按“杠开全球独钓自摸”结算，不再计算对对胡分。

单份胡牌分：

```text
底分10
+ 全球独钓80
+ 杠开20
+ 花分
+ 其他实际可叠加牌型分
```

若实际满足门清，再加门清10分。

B承包三家份额：

```text
3 × 单份胡牌分
```

敞开头比下胡后：

```text
3 × 单份胡牌分 × 2
```

补杠分单独实时结算：

```text
补杠基础分10 × 比下胡2 = 20
```

“杠开”只作为牌型加20分，不会再额外将胡牌结果乘3。

杠开包子属于三嘴包子的特殊结算，承包优先级仍按“三嘴包子”处理。

## 26. 一将牌与第16局特殊续庄

### 26.1 一将牌

完整一场16个有效庄次称为“一将牌”。

MVP 必须由系统自动推进和结束一将牌。房主提前结束或解散房间可以作为附加管理功能，但不能作为正常完成一将牌的替代方案。

程序必须记录：

- 当前有效庄次；
- 当前圈数；
- 当前庄家；
- 当前是否处于第16局；
- 第16局特殊续庄状态。

### 26.2 第16局的结束条件

进入第16局后，只有某一局同时满足以下条件时，一将牌才正式结束：

1. 本局不属于原有不过庄情况；
2. 本局没有触发第16局额外续庄条件；
3. 本局结束后可以正常过庄。

若触发任意不过庄或额外续庄条件，则由第16局庄家继续坐庄，重新开始下一局；新一局仍属于第16局。

每次重新开始第16局时，上局中的所有局内计数清零，重新统计。

### 26.3 原有不过庄情况

以下情况本来就不过庄：

- 庄家胡牌；
- 杠开；
- 一炮多响；
- 抢杠胡；
- 三嘴包子；
- 三清包子；
- 全球包子；
- 流局。

### 26.4 第16局额外续庄条件

第16局中出现以下任意情况，即使原本应正常过庄，也不结束一将牌：

1. 任意形式的自摸；
2. 发生“跟打一圈”罚分；
3. 发生“同一玩家打出四张相同牌”罚分；
4. 发生四风归齐；
5. 本局出现至少一次成功暗杠；
6. 本局全桌累计出现至少两次成功的直接明杠或补杠；
7. 出现花杠；
8. 有人胡大牌。

补充规则：

- 自摸包括普通自摸、花开、杠开、地胡自摸等所有自摸；
- “罚分”只指本规范罚分章节中的两种罚分，不包含普通杠分、胡牌付款或其他正常付款；
- 承包付款本来就按原有不过庄规则处理；
- “两次明杠”不要求由同一玩家完成；
- 直接明杠和补杠均计入次数；
- 暗杠单独判断，出现一次即触发续庄；
- 声明但未成功成立的杠不计入；
- 花杠出现一次即触发续庄。

### 26.5 大牌定义

如果胡牌最终只有以下情况之一，则不算大牌：

- 仅平胡；
- 门清＋平胡。

只要胡牌还包含任意其他胡牌牌型或特殊胡牌项目，就算大牌。

包括但不限于：

- 对对胡；
- 全球独钓；
- 混一色；
- 清一色；
- 七对；
- 龙七对；
- 无花果；
- 压绝；
- 地胡；
- 花开；
- 杠开；
- 天胡；
- 以上任意牌型与门清的组合。

例如：

- 门清＋清一色：算大牌；
- 门清＋无花果：算大牌；
- 仅门清平胡：不算大牌。

## 27. 程序实现约束

### 27.1 服务器权威

- 服务器是唯一权威状态来源；
- 客户端只能提交操作意图；
- 客户端不能自行决定操作是否合法、是否胡牌或如何计分。

### 27.2 隐藏信息

任何玩家只能看到：

- 自己的手牌；
- 所有公开花牌；
- 所有副露；
- 所有弃牌；
- 公共状态。

不能看到其他玩家的手牌内容。

### 27.3 规则判定

程序必须明确记录：

- 当前玩家；
- 当前庄家；
- 牌墙头尾；
- 每名玩家手牌、副露、花牌、弃牌；
- 门清状态；
- 地胡状态；
- 过手状态；
- 连续风牌记录；
- 同牌弃牌计数；
- 跟打一圈状态；
- 杠后承包人及持续状态；
- 三嘴锁定对象、嘴数和失效状态；
- 三清类别和失效状态；
- 全球架牌、范围和是否失效；
- 各种实时分数记录；
- 有效过庄次数；
- 当前是否处于第16局；
- 第16局特殊续庄状态。
