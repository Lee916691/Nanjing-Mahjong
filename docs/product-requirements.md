# Product Requirements

## Goal

Create a browser-based four-player Nanjing Mahjong experience.

## Current Scope

- Project scaffold only.
- Frontend health display.
- Backend health endpoint.
- Minimal Socket.IO connection.

## Out of Scope For This Task

- Login.
- Rooms.
- Tile wall, shuffle, draw, discard, melds, win checks, or scoring.
- Database.

## To Confirm

- Supported devices and browsers.
- Match flow and reconnection expectations.
- Rule variants for Nanjing Mahjong.
- Spectator or replay requirements.
